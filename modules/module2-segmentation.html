Golden Rules

The 6 golden rules of tracking segmentation

01
Market code must match in PMS, CRS, and RMS.all three systems, every time.
02
The Loyalty code is exclusively for the Dusit Gold programme. No other use.
03
All OTA bookings use the E-Commerce code. No exceptions.
04
Keep it simple. The main reason defines the motive of the whole stay.
05
Free-of-charge rooms in a group or contract take the same code as the core business.
06
Market code is set at time of booking and never changes, even for groups.
On every shift

Do / Don't

Do
✓
Set the market code at booking. It never changes.
✓
Use the E-Commerce code for every OTA booking.
✓
Same market code in PMS, CRS, RMS.
✓
Ask where the guest lives, not where they're from.
✓
Complimentary rooms take the group's code.
Don't
✗
Change the market code after booking.
✗
Use the Loyalty code for anything but a Dusit Gold rate.
✗
Use the Accounts Transfer code. Finance Dept. only.
✗
Guess the country code. Check the ISO list.
✗
Leave any tracking field blank.
